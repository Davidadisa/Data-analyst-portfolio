# 📚 Amazon Kindle Review Sentiment Analysis

This project uses machine learning to analyze over 980,000 Amazon Kindle reviews and determine if they're positive or negative.

## 🧰 Tools Used
- Python
- Pandas, NLTK
- TF-IDF, CountVectorizer
- Logistic Regression, SVM, Random Forest, LSTM

## 💡 Key Insights
- Most Kindle reviews are positive.
- Naive Bayes gave 91% accuracy out of the box.
- After tuning, we reduced word features from 80k to 3.6k without losing accuracy.

## 📁 Dataset
- From Kaggle and GitHub: `Amazon Kindle Store Reviews (2000–2014)`
